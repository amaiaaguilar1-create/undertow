# Undertow prototype

Clickable prototype for **Undertow**, a 28-day safety benchmark for how chatbots treat teens. Built for DPI-678M, Product Management and Society (Harvard Kennedy School, Prof. Kathy Pham).

Open it here: https://amaiaaguilar1-create.github.io/undertow/

All data is sample data. Every teen in the prototype is simulated; no real teen's words are used.

Suggested path: start the run on "Set up a benchmark run", select day 24 on "Run status", choose "Read how the chatbot answered", then open the "Day 24, fresh start" tab.
